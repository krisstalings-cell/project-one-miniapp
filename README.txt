PROJECT ONE Mini App - مرحله ۱

فایل‌ها:
- index.html
- style.css
- app.js

اجرا:
1) این سه فایل را روی یک هاست HTTPS قرار بده.
2) index.html باید از طریق HTTPS قابل دسترسی باشد.
3) در Telegram Mini App، URL همین index.html را تنظیم کن.
4) ربات باید دکمه‌ای داشته باشد که Web App را باز کند.

این نسخه شامل:
- صفحه خانه
- کارت‌های دسترسی سریع
- نوار پایین
- منوی کناری
- FAB
- Bottom Sheet
- پیام Toast
- اتصال اولیه به Telegram WebApp API

هنوز به Backend یا دیتابیس وصل نشده است.
